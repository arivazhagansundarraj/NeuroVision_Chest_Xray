Welcome to PulmoScan

AI-assisted chest X-ray classification platform designed to analyze radiographs and classify them as pneumonia or normal.

Project Overview

PulmoScan is a deep learning based chest X-ray classification system. The application processes an uploaded X-ray image using a trained model and provides a classification result together with the model confidence.

System Information

  • Input: Chest X-ray Image
  • Image Size: 128 × 128
  • Model: Deep Learning (CNN)
  • Output: Pneumonia / Normal
System Note: PulmoScan is an AI-assisted research and educational system. Its predictions should not be considered a medical diagnosis.
